# Delivery Checklist

## Input Gate
- 设计稿或交互稿链接
- 需求说明或验收标准
- 接口文档：字段、类型、是否必填、错误码、分页/刷新口径
- 埋点要求：事件名、触发时机、字段来源
- 页面/接口入口：路由、宿主页面、来源链路、调用方

## Cross-Team Alignment
- 前端关注：视觉、交互、文案、资源、动效、空态/错误态
- 后端关注：字段、时序、兼容逻辑、错误码、幂等、缓存/刷新口径
- 客户端关注：模型映射、页面生命周期、本地状态、埋点、前后台切换、弱网

## Verification
- 标准态验证
- 长文案/空值/缺字段验证
- 错误码与降级验证
- 弱网/重试/重复进入验证
- 前后台切换与页面重进验证
- 埋点触发时机与字段来源验证

## Review Focus
- 字段映射是否错位
- 状态机是否与产品口径一致
- 埋点是否遗漏或口径错误
- 幂等和重复触发是否安全
- 页面生命周期是否导致重复展示、漏展示、错展示
- spec 是否已同步更新
