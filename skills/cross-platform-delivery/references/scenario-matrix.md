# Scenario Matrix

## 新功能交付
优先顺序：
1. 输入门禁
2. 复用检索
3. 字段/状态/埋点映射
4. 交付方案
5. memory
6. CR

## 联调排障
优先顺序：
1. 现象与复现条件
2. 请求/响应口径
3. 前后端状态是否一致
4. 客户端生命周期与缓存
5. 埋点与日志
6. 最小验证路径

## 代码审查
优先顺序：
1. 字段映射
2. 状态机
3. 生命周期
4. 幂等与重复触发
5. 埋点
6. memory / 测试缺口

## 重构或迁移
优先顺序：
1. 旧逻辑 inventory
2. 风险边界
3. 新旧字段映射
4. 兼容与回滚方案
5. 增量迁移步骤
6. 回归范围
