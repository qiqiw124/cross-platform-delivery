# Scenario Matrix

## 新功能交付
优先顺序：
1. 输入门禁
2. 复用检索
3. 字段/状态/埋点映射
4. 交付方案
5. 并行拆 frontend / backend / client 实现分支（若边界清晰）
6. spec
7. CR

## 联调排障
优先顺序：
1. 现象与复现条件
2. 请求/响应口径
3. 并行核对前后端状态 / 客户端生命周期 / 埋点与日志（若验证路径独立）
4. 最小验证路径

## 代码审查
优先顺序：
1. 字段映射
2. 并行检查状态机 / 生命周期 / 幂等与重复触发 / 埋点（若检查主题独立）
3. spec / 测试缺口

## 重构或迁移
优先顺序：
1. 旧逻辑 inventory
2. 风险边界
3. 新旧字段映射
4. 兼容与回滚方案
5. 并行拆增量迁移分支（按仓库或模块）
6. 回归范围
