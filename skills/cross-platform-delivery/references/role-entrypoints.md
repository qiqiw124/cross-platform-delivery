# Role Entrypoints

## Frontend
适合这类请求：
- “帮我把这个需求拆成前端/后端/客户端字段映射”
- “这个页面的状态和接口怎么对齐”
- “联调前先梳理一下前端依赖和埋点”

输出重点：
- 页面状态
- 文案与资源来源
- 接口依赖
- 埋点触发时机

## Backend
适合这类请求：
- “帮我看接口字段设计是否能支撑三端”
- “这几个错误码和状态机要怎么统一”
- “帮我梳理联调需要的 mock 和异常 case”

输出重点：
- 字段口径
- 返回时序
- 幂等与兼容
- mock / 真接口联调方案

## Client
适合这类请求：
- “帮我把这个需求落成客户端实现方案”
- “这几个字段在页面生命周期里怎么处理”
- “埋点、缓存、前后台切换会不会有问题”

输出重点：
- 模型映射
- 生命周期
- 本地状态
- 回归与 memory

## Cross-Team
适合这类请求：
- “三端一起梳理下这个需求怎么交付”
- “这个联调问题可能出在哪一层”
- “给我一份可直接发群里的对齐说明和验收清单”

输出重点：
- 统一口径
- 冲突点
- 风险清单
- 验收路径
