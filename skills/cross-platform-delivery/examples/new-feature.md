# Example: New Feature

## Input
- 设计稿：业务页面新增活动入口卡片
- 接口：返回标题、副标题、跳转链接、活动ID、按钮状态
- 埋点：曝光、点击
- 入口：业务首页

## Expected Output Shape
1. 输入门禁结果
2. 复用检索结果
3. 字段/状态/埋点映射表
4. 交付方案
5. 联调方案
6. spec更新建议
7. CR关注点
8. 验收清单

## Key Review Points
- 标题/副标题是否直接来自后端
- 按钮状态是否由客户端二次映射
- activity_id 是否直接取接口字段
- 空态/禁用态/弱网态是否有兜底
